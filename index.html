About

Developer, student,
and occasional designer.

I'm based in Kenya, working across software development and my studies, usually with more than one project running at once. My focus is edtech and SaaS products built specifically for the Kenyan and East African market — which means designing around things like M-Pesa payments, the KCSE and CBC curricula, and Swahili-language content from the start, not bolting them on later.

Most of my recent work has gone into GilaniAI, an AI tutoring platform — everything from security hardening (row-level security across every table, UUID validation, rate limiting, prompt injection sanitization) to features students actually ask for, like speech-to-text, math rendering, and realtime notifications. I refactored the codebase from one large monolithic route file into modular components as it grew.

My workflow leans on small, verifiable changes — targeted terminal patches, careful grep verification, TypeScript checks before anything ships. I recently did a full migration off Windows to a customized Ubuntu setup with GNOME and Zsh.

Outside of code, I care about how things look — logo work, brand systems, and UI design show up alongside the engineering, not separately from it.
