# Testing the Cayman Theme

This page is rendered using Jekyll and the remote Cayman theme we configured.

Because this markdown file contains "front matter" (the `---` block at the very top), Jekyll automatically wraps it in the theme's layout and styles it. 

### Why didn't this happen to the main portfolio?
Your main `index.html` file *does not* have front matter, so Jekyll serves it as raw HTML, preserving your 100% custom, modern dark-mode design.

You can mix and match! You could have your custom portfolio on the main page, and use Jekyll themes for things like a `/blog` or `/docs` by just writing markdown files.
