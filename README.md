Personal portfolio site for **Onunga Elly**, software developer and student based in Nairobi, Kenya. Built to present edtech and SaaS work to companies and collaborators.

🔗 **Live:** [justolise.github.io/portfolio](https://justolise.github.io/portfolio)

---

## Structure

```
portfolio/
├── index.html   # Markup — pages, sections, content
├── styles.css   # Design tokens, layout, all component styles
├── main.js      # Navigation, scroll-reveal, card spotlight
└── README.md
```

## Features

- **Dark minimal design** — deep neutral palette with gold accents
- **Single-page navigation** — Home, Projects, About, Contact with hash-based routing
- **Scroll-reveal animations** — elements fade in as they enter the viewport
- **Card spotlight effect** — radial glow follows the cursor on hover
- **Glassmorphism header** — sticky nav with backdrop blur
- **Animated status badges** — Live (green pulse), In progress (amber), Exploratory (grey)
- **Fully responsive** — mobile hamburger menu, fluid type, stacked layouts on small screens

## Tech

Plain **HTML · CSS · JavaScript** — no frameworks, no build step, no dependencies.  
Fonts loaded from Google Fonts (Inter, Instrument Serif, JetBrains Mono).
